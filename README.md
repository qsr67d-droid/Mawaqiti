# مواقيتي 3.0

تطبيق مواقيت صلاة وأذان عربي RTL، يعمل على Android 6.0+.

## ما تم مراجعته
- GPS: FINE + COARSE مع طلب الموقع الحديث عند الحاجة.
- الإنترنت: HTTPS فقط مع مهلات اتصال وقراءة ورسائل خطأ.
- مواقيت الصلاة: AlAdhan، طريقة 5 (Egyptian General Authority of Survey) وschool=0.
- وضع عدم الاتصال: حساب محلي احتياطي بدل ظهور --:-- إذا تعذر الوصول للخدمة.
- الأذان: ملف `app/src/main/res/raw/adhan.mp3` المدمج من الملف الذي أرسله المستخدم.
- الصوت: مستوى افتراضي 20% وقابل للتعديل، مع Audio Focus.
- الخلفية وقفل الشاشة: جدولة AlarmManager دقيقة عند توفر إذن المنبهات، مع دعم Doze عبر setExactAndAllowWhileIdle.
- Android 13+: استخدام USE_EXACT_ALARM للتطبيق الذي تعتمد وظيفته الأساسية على المنبه الدقيق.
- Android 12 وأقل حتى API 32: SCHEDULE_EXACT_ALARM.
- إعادة الجدولة بعد الإقلاع، تغيير الوقت والمنطقة الزمنية، وتحديث الحزمة.
- واجهة WebView محلية لا تعتمد على localhost أو Chrome.
- تصميم داكن عربي احترافي وأيقونة هلال/مسجد.

## الحساب المحلي
الحساب الاحتياطي يستخدم زاوية فجر 19.5° وعشاء 17.5°، والعصر على مذهب الشافعي/الظل 1، مع تصحيح المنطقة الزمنية من الجهاز.

## ملاحظة
لأفضل دقة، أول تشغيل يحتاج السماح بالموقع. وللأذان الدقيق على Android 12، يجب السماح للتطبيق بصلاحية «المنبهات والتذكيرات».
